Write the year down.
Then lock it forever.

Memolock is a small offline app for recording one honest report for each completed year. Track books, places, habits, custom notes, and personal numbers—then permanently lock the report so it cannot quietly be rewritten later.

Download on Github See how it works

Portable, private, and entirely offline. No installer or account required.

How it works

One report for each completed year.

01

Start the report

When a new year arrives, Memolock opens a report for the year you just completed. The report year is assigned automatically and cannot be changed.

02

Record what mattered

Add books, places, sleep, steps, exercise, albums, and a quote from the year. You can also create custom text and number entries for anything else worth remembering.

03

Lock it forever

When the report is finished, lock it permanently. It remains readable and exportable, but it can never be edited or unlocked again. The following year receives a separate report.

Compare years

See what changed

Compare the standard numbers from your reports using an offline chart. Custom entries remain available as written summaries beneath the chart.

The lock

Permanent, on purpose

Once a report is locked, it becomes permanently read-only. There is no unlock date and no way to reopen it for editing. That is the deal: write it honestly, lock it, and leave it alone.

What locking does Locking protects that year from future edits and automatically exports a portable .memolock copy. It does not delete anything or affect reports from other years.

Portable reports

Take your memories with you

Locked reports are exported to your Documents folder as readable .memolock files. You can import them later using the file picker or drag and drop.

Each file records the report data and whether it was locked. Existing permanently locked years cannot be replaced through importing.

Storage

Stays on your device

Your main archive lives in a readable JSON file beside the app. Portable .memolock copies are stored in Documents\Memolock.

There are no accounts, analytics, cloud services, or background uploads. Your reports remain plain local data under your control.
